This site showcases my work across full-stack software development, AI-assisted applications, computational modeling, and academic research:

* **Zaino — Visual & Geometry Challenge:** Full-stack puzzle game featuring server-side scoring and a RAG-powered AI assistant built with Python, Django REST, LangChain, Groq, Chroma, React, and TypeScript.
